# 📂 Raw Data

The project uses a marketing campaign performance dataset containing information about campaign budgets, advertising spend, clicks, conversions, revenue, platforms, content types, target audiences, regions, and campaign dates.

The original/raw dataset is kept separately from the cleaned and processed datasets used for analysis.

## 📥 Dataset Source

The raw marketing campaign dataset is used as the starting point for the complete analytics workflow.

The dataset contains **1,000 marketing campaign records** and includes fields such as:

- `Campaign_ID`
- `Budget`
- `Clicks`
- `CTR`
- `CPC`
- `Conversions`
- `CPA`
- `Conversion_Rate`
- `Duration`
- `Platform`
- `Content_Type`
- `Target_Age`
- `Target_Gender`
- `Region`
- `Revenue`
- `Spend`
- `ROAS`
- `Date`
- `Impressions`
